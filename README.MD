# 🚀 Code Nexus

Master DSA Pattern by Pattern.

Code Nexus is a modern DSA learning platform designed to help students prepare for coding interviews through a structured roadmap. Instead of solving random problems, users practice curated LeetCode questions pattern-by-pattern while tracking their progress.

---

## ✨ Features

* 📚 Pattern-based DSA roadmap
* 🎯 Curated LeetCode problems
* 📈 Progress tracking
* 🔍 Search and filter problems
* 📱 Responsive UI
* ⚡ Fast and modern interface
* 🔗 Direct links to LeetCode questions

---

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/CodeNexus.git
cd CodeNexus
```

---

### 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

---

### 3. Install Backend Dependencies

```bash
cd ../backend
npm install
```

---

### 4. Run the Frontend

```bash
cd ../frontend
npm run dev
```

The frontend will start on:

```text
http://localhost:5173
```

---

### 5. Run the Backend

Open a new terminal and run:

```bash
cd backend
npm run dev
```

The backend will start on:

```text
http://localhost:5000
```
